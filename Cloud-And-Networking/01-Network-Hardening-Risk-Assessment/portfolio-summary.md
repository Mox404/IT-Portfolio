# Portfolio Summary

## Project

Network Hardening Risk Assessment

## Short Description

Created a simulated security risk assessment for a social media organization after a data breach involving customer personal information. The project identifies major vulnerabilities and recommends practical network hardening methods to reduce future breach risk.

## Vulnerabilities Reviewed

* Employees share passwords.
* The database admin password is set to the default.
* Firewall rules are not configured to filter traffic.
* Multifactor authentication is not used.

## Hardening Methods Selected

* Multifactor authentication.
* Password policy and least privilege access control.
* Firewall maintenance and port filtering.

## Key Recommendation

The organization should prioritize credential security and traffic filtering. MFA and stronger password/access controls reduce unauthorized account access, while firewall maintenance and port filtering reduce unnecessary network exposure.

## Skills Demonstrated

* Network hardening analysis
* Vulnerability prioritization
* Access control recommendations
* MFA and password policy evaluation
* Firewall and port filtering concepts
* Security risk documentation
* Remediation planning
