# Botium Toys Security Audit

This came from the Google Cybersecurity course. Botium Toys is a fictional company, so I keep this as coursework rather than pretending it was a real audit.

The exercise was useful because it made me look at security controls from a business risk angle instead of only a technical one.

## What I looked at

I reviewed things like:

* access control and least privilege
* passwords and privileged access
* encryption and data protection
* backups and disaster recovery
* intrusion detection
* physical controls
* PCI DSS and GDPR awareness

The biggest gaps in the scenario were broad access, no encryption for sensitive data, weak backup and recovery planning, no IDS, and weak password management.

My main recommendations were to tighten access, encrypt sensitive data, build proper backup and recovery procedures, improve monitoring, and clean up account controls.
